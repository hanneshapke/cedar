# YouTube: titles and descriptions

One upload per film. The chapter times are the scene starts of each film's own take
(`timeline.json`, `timeline.<lang>.json`); the title card is part of the first chapter, because
YouTube wants chapters of at least ten seconds. If a film is recorded again, the times change
with it.

YouTube does not read the subtitle track inside the MP4: upload the matching captions file under
Subtitles for each video.

| Language | Film | Captions |
| --- | --- | --- |
| English | `cedar-intro-narrated.mp4` | `captions.srt` |
| Deutsch | `cedar-intro-narrated.de.mp4` | `captions.de.srt` |
| Français | `cedar-intro-narrated.fr.mp4` | `captions.fr.srt` |
| Español | `cedar-intro-narrated.es.mp4` | `captions.es.srt` |

Each description ends by saying that the model's answers in the demo are scripted (see
"What is real and what is scripted" in the README).

## English

Title:

```
Meet Cedar: your own AI assistant that runs at home
```

Description:

```
Cedar is a free, open source AI assistant that runs on your own computer and does real work for you. It plans the task, does it in a sealed box, and shows you what it did.

In this four-minute tour:
• Add a model: run one yourself, use a hosted provider, or point Cedar at a server you already run
• Give it a task and see its plan before any work starts
• Watch it work in an isolated container, then open every step
• An interactive chart and a finished PDF
• Cedar asks before anything risky
• Memory you can see, pin and remove
• A switch for every ability
• Turn a conversation into an agent that runs on a schedule

Chapters
0:00 First start
0:21 Adding a model
1:04 Giving it a task
1:20 The plan
1:36 Working in a sealed box
2:01 The result
2:26 Asking before anything risky
2:41 Memory
3:04 A switch for every ability
3:18 From conversation to agent
3:40 Where to get it

Cedar runs on Mac, Windows and Linux, with apps for iPhone and Android. Apache 2.0.
https://github.com/hanneshapke/cedar

Subtitles are available in the player. Cedar, its chat and the sandbox are the real software; the model's answers in this demo are scripted so the recording is repeatable, and the spending data is invented.

#Cedar #AIassistant #opensource #selfhosted #localAI
```
