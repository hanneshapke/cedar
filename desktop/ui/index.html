Release notes
Use Cedar running on another computer

If Cedar already runs on a computer that stays on (a DGX Spark, a mini PC, another Mac), this app can show that server’s chat instead of running its own. Scheduled agents then keep running there while this computer sleeps, and their notifications can show up here (with Desktop notification picked in that chat’s Settings → Notifications). This computer needs no Docker or model server. Conversations and agents stay on that server.

Copy both from the other computer: in the chat’s Settings → Phone, or on the Cedar app’s setup page under iPhone, iPad & Android. The address is its https:// address on your tailnet.

iPhone, iPad & Android

The Cedar iOS and Android apps connect over HTTPS only. Cedar can serve the chat on your Tailscale network with tailscale serve, so devices logged in to the same tailnet reach it and nothing else does. This needs Tailscale on this computer and the phone, and MagicDNS and HTTPS Certificates turned on in the admin console. Turning it on or off restarts Cedar once, so the chat learns its new address; a response still running is stopped.

In the Cedar app’s Settings (iOS or Android), tap Scan QR Code and point the camera here. The code holds the access token, so hide it again when you are done.
